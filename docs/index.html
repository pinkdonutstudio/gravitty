A terminal that drops out of the notch.

Press a hotkey and Gravitty grows out of the notch. Press it again and it hides, and your shells keep running.

Download for macOS View on GitHub

What it does

  • Long-living sessions. Hiding the panel never closes a shell. Only quitting the app does.
  • Notch native. It grows out of the real notch. On a screen without one, it draws a notch so it looks the same.
  • Tabs and splits inside the panel, with the keys you expect.
  • Agent glance. Hover the notch to see what your Claude Code and Kiro CLI sessions are doing: context, tokens, plan limits, running sub-agents.
  • Running light. A light travels around the notch while an agent works: orange for Claude, purple for Kiro. It flashes green and plays a sound when one finishes.
  • Local and private. It reads local files only, with no accounts and no telemetry. The one network call is the update check.

Requirements

  • macOS 14 or later on Apple silicon. The default hotkey is ctrl + `, and you can change it in Settings.
